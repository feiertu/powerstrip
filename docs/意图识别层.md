# 意图识别层（两段式 LLM 调用链）

把"主观题"（用户一句话）压缩成"选填题"（受 catalog 约束的 manifest 答卷），然后交给 generator 单次确定性生成。

## 调用链

```
用户一句话
  │
  ▼ [A1] 路由调用（1 次模型调用）
  │   输入：需求原文 + 7 大类封闭选项表
  │   输出：7 个分类逐一表态 selected/terminated（"+终止"强制全覆盖，防漏识别）
  ▼ [A2] 并行填充（每个选中分类 1 次模型调用，Promise.all 并发）
  │   输入：需求原文 + 该分类的插座参数档位（choice 选项/正则/必填全量给出）
  │   输出：该分类的 selections+params
  ▼ [B] 确定性合并器（无模型，纯函数）
  │   键 = (插座, 注册名/类名)；同键同参 → 幂等去重；同键异参 → 冲突仲裁调用
  ▼ [C] 校验（expandGraph + 保护门干跑，不落盘）
  │   失败 → 错误归属到分类（错误信息里的插座名 → 分类）→ 重填该分类（错误注入，最多 2 轮）
  ▼ [D] 单次代码生成（generator 一次运行，确定性、可复现）
```

- **单次模型调用**：`--mode single`，一次调用直接产出完整 categories，走同一条合并/校验/生成流水线。
- **单次业务请求**：以上整条编排（A→D）一次完成。
- **单次代码生成**：D 阶段，引擎层面始终只有一次。

## 重试条件与合并机制

| 失败类型 | 处置 | 上限 |
|---|---|---|
| 模型输出无 JSON / 解析失败 | api provider 内部重试一次 | 2 次 |
| 路由未覆盖 7 类 / 出现未知分类 | 直接报错（provider 契约违反） | — |
| 校验失败（参数档位/引用/派生） | 错误归属分类 → 重填该分类（错误注入提示词） | 2 轮 |
| 同注册名参数冲突 | 仲裁调用（keep=a/b），合并器禁止自己拍板 | 每冲突 1 次 |

合并键参数：`regPath/registryPath/recipeId/professionName/woodName/tagPath/keyPath/rulePath/dimPath/modifierRegPath/beRegistryPath/menuRegistryPath/biomePath/layerPath/featureKeyPath/poiRegPath/trunkRegPath/foliageRegPath`（无注册名类插座以 ref 为键）。

## Provider

| Provider | 说明 |
|---|---|
| `--provider mock` | 离线确定性降级：22 个关键词场景（抛光台/探测器/作物/告示牌/音效/生物/船/盔甲/燃料/投掷/矿物/树/维度/战利品/标签/数据生成/JEI/事件/食物/工具/标签页/村民），参数集复用已过护栏的示例答卷。测试与离线演示用。 |
| `--provider api` | OpenAI 兼容接口（DeepSeek 等）。环境变量：`POWERSTRIP_API_URL`（默认 `https://api.deepseek.com`）、`POWERSTRIP_API_KEY`、`POWERSTRIP_MODEL`（默认 `deepseek-chat`）。`response_format=json_object` + temperature=0。 |

未设置 `POWERSTRIP_API_KEY` 时默认走 mock 并给出提示。

## 用法

```bash
# 两段式（默认）
node intent/index.js "我想要一个带GUI的抛光台，还有能扫描矿石的金属探测器" --provider mock

# 单次模式
node intent/index.js "帮我做一颗松树和一片蓝宝石矿" --provider mock --mode single

# 真实 API
POWERSTRIP_API_KEY=sk-xxx node intent/index.js "做三个矿物和一个传送门" --provider api

# 只识别不生成
node intent/index.js "..." --provider mock --no-gen

# 测试套件（9 项，无网络）
node scripts/intent-chain.test.js
```

输出目录（默认 `out-intent/`）：`manifest.json`（合并后答卷）+ generator 全部产物 + `ASSEMBLY.md`（派生链可追溯）。

## 已实现 / 未实现

- ⚠️ api provider 的**真实网络调用未在本环境验证**（沙箱禁外联，且无 API Key）；提示词与 JSON 解析已按接口契约实现，待真实 Key 实测——挂账【测试结果】。
- ⬜ 批量意图的多实例深度场景（两个带 GUI 方块同现）未做端到端用例；mock 仲裁固定 keep=a（真 provider 会走 LLM 判断）。

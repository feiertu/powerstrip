# 资源层防错乱

生成器在产出 Java 后，再产出资源文件（assets/data），并用三道闸防错乱。三道闸全部失败即中断生成，报"保护门拦截"。

## 三道闸

### 闸一：资源路径所有权表（防重复/冲突）

`lib/assets.js` 的 `AssetRegistry` 为每个输出路径登记 owner；同一路径被两个不同 owner 生成 → 直接拦截。
owner 粒度 = 插座 + 类名（同插座多实例互不相同）。

```text
保护门拦截：资源路径冲突 —— "src/main/resources/assets/tutorialmod/textures/entity/shared.png"
同时被 socket:creature-entity#AlphaEntity 与 socket:creature-entity#BetaEntity 生成。
```

验证：`scripts/resource-layer.test.js`「两个实体共用贴图路径 → 所有权表拦截」（负例）。

### 闸二：客户端/服务端一致性（防端侧错乱）

catalog 中 `clientClasses` 声明每个插座产出的客户端类。生成后 `lib/checks.js` 静态核查：
客户端类名只允许出现在——

1. 自身定义文件（`X.java`）；
2. 客户端目录：`entity/client/`、`block/entity/renderer/`、`compat/`；
3. 主类的 `ClientModEvents` 内部类区块（大括号配对定位，逐行判定）；
4. `ModEventBusClientEvents.java`。

import 行不参与判定（import 不触发类加载，引用位置才关键）。违规例：把渲染器注册写进主类构造器（服务端会类加载客户端代码 → 崩溃），会被指向具体文件:行号。

### 闸三：NBT 键对称（防持久化错位漂移）

对每个 `block/entity/custom/` 下的方块实体，提取全部 `put*/get*("键")` 字面量并比较集合：

```text
保护门拦截：生成后静态核查失败 ——
  - src/main/java/.../BadBE.java NBT 键不对称：只写 [a.b]，只读 [x.y]
```

键由模板单一来源生成（save/load 两侧共享同一 params），核查兜底防手工漂移。

## 资源生成范围

| 插座 | 生成物 |
|---|---|
| block-registry | blockstate（cube / 三轴 column）、models/block、models/item、1×1 占位贴图；modelStyle=custom 时留白不生成 |
| crop-block | 0..maxAge 全阶段 blockstate + stage 模型 + 物品模型 + 贴图占位 |
| item-registry | 物品模型 + 贴图占位（含种子、自定义物品） |
| block-with-gui | GUI 贴图占位（textures/gui/<path>.png） |
| creature-entity | geo（单骨骼脚手架）、animation（含 idle/walk 动画名，与 ModAnimationDefinitions 闭环）、贴图占位 |
| sound-registry（聚合） | sounds.json + 语言字幕键 |
| 全部（聚合） | en_us.json：方块/物品/标签页/实体/村民职业/字幕键 |
| custom-recipe | 配方数据 JSON（type/ingredient/input_count/output，与序列化器字段一致） |
| add-item-modifier | global_loot_modifiers.json + 条目 JSON（added_item 为 ItemStack.CODEC 形态） |
| custom-tags | tags/blocks|items/<path>.json（空 values） |

占位贴图为合法 1×1 透明 PNG（魔数与 IHDR 尺寸有测试断言），替换真实美术即可，路径已由所有权表锁定。

## 明确留白（防误导优先于凑数）

- 告示牌模型/blockstate（modelStyle=custom，不生成错误模型）；
- 维度/群系/level_stem/群系修饰的数据 JSON；
- 方块战利品表 JSON（datagen Provider 覆盖一部分）；
- 音效 ogg 本体（sounds.json 已生成，缺 ogg 只告警不崩溃）；
- 实体数据持久化（当前生物实体无 save/load，闸三仅覆盖方块实体）。

## 测试

```bash
node scripts/resource-layer.test.js   # 15 项：生成正确性 + 三道闸正/负例 + 占位 PNG 合法性
```

## 已知限制

- 三道闸均为**静态核查**，运行期行为（真实双端启动）仍需 MDK 实测，挂账【测试结果】；
- side 核查基于"类名出现在哪些文本区域"，对反射/字符串类名的引用无法发现；
- NBT 核查只覆盖字符串字面量键，非字面量（拼接键）不在范围（模板不会生成拼接键）。
